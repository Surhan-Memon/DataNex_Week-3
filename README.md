# Handwritten Digit Recognition Using Neural Networks

This is a simple deep learning project using Python, TensorFlow, and Keras.

The model is trained using the MNIST dataset, which contains handwritten numbers from 0 to 9. The neural network learns patterns from the handwritten images and then predicts which number is shown in an image.

# What I Used
Python
NumPy
TensorFlow
Keras
MNIST Dataset
# How It Works
Load the MNIST dataset.
Normalize the image pixel values.
Create a simple neural network.
Train the model using handwritten digit images.
Test the model and check its accuracy.
Use the trained model to predict a handwritten digit.
# Neural Network

The model contains:

Flatten layer
Dense hidden layer with 128 neurons
Output layer with 10 neurons for digits 0–9
ReLU activation
Softmax activation
Run the Project
